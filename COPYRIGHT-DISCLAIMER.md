## 📹 YouTube Videos - Important Information

### **Embedding vs. Hosting**

**✅ What We're Doing (LEGAL):**
- **Embedding** YouTube videos using YouTube's official embed feature
- Videos are **NOT downloaded or hosted** on our server
- Videos remain on YouTube's servers
- YouTube's own terms of service allow embedding

**❌ What We're NOT Doing:**
- NOT downloading videos
- NOT re-uploading videos
- NOT claiming ownership
- NOT removing watermarks or credits

### **Why Embedding is Legal:**

1. **YouTube's Terms of Service** explicitly allow embedding
2. **"Share" Feature** - YouTube provides embed codes for this purpose
3. **No File Storage** - Videos stream from YouTube, not from our server
4. **Original Creator Gets Views** - Views count for original video owner
5. **Educational Fair Use** - Academic/educational use is protected

## 📚 Fair Use Doctrine (Educational Context)

### **What is Fair Use?**

Under copyright law (Section 107 of the Copyright Act), educational use of copyrighted material is often considered "fair use" when:

1. **Purpose**: Educational/non-commercial ✅
2. **Nature**: Publicly available content ✅
3. **Amount**: Links only, not full reproduction ✅
4. **Effect**: No market harm to original ✅

### **Our Use Qualifies Because:**

✅ **Non-Commercial** - No profit, no ads, no monetization  
✅ **Educational** - College course project  
✅ **Transformative** - Used in educational context  
✅ **Minimal Use** - Only embedding, not hosting  
✅ **Attribution** - Links directly to original source  
✅ **No Competition** - Doesn't replace original videos

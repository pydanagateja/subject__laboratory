```javascript

```

### **Extraction Process:**
1. Component extracts YouTube video ID from URL
2. Constructs thumbnail URL automatically
3. Sets as background image
4. Adds play button overlay
5. Handles click to navigate

### **Supported URL Formats:**
- ✅ `youtube.com/watch?v=VIDEO_ID`
- ✅ `youtu.be/VIDEO_ID`
- ✅ `youtube.com/embed/VIDEO_ID`
